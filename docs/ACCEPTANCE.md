# Criterios de aceptación del MVP C

La fase se considera funcionalmente completa cuando:

- el visitante puede entender el servicio y sus requisitos;
- puede ver salidas y plazas;
- puede registrar una reserva;
- la reserva reduce la disponibilidad;
- el administrador puede crear y bloquear salidas;
- puede consultar los participantes por salida;
- puede preparar el listado para WhatsApp;
- los datos sobreviven a una recarga en el mismo navegador;
- la interfaz se adapta desde móvil hasta escritorio;
- el alcance y sus limitaciones quedan documentados.
