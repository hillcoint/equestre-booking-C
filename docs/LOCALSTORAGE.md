# localStorage

La elección de localStorage es temporal e intencionada para el MVP.

Ventajas en esta fase:

- cero infraestructura;
- funcionamiento inmediato;
- fácil clonación y ejecución local;
- permite validar reservas y administración.

Limitación esencial: cada navegador posee su propia copia de los datos. Por tanto, no sirve como persistencia compartida para reservas reales de varios clientes.
