# UX notes

La landing prioriza un recorrido sencillo:

1. entender rápidamente qué ofrece el centro;
2. consultar próximas salidas;
3. comparar nivel, horario, precio y plazas;
4. reservar;
5. consultar requisitos y seguridad antes de acudir.

La administración permanece accesible desde cabecera únicamente por tratarse de una demo. En una versión real debería separarse del recorrido público y protegerse mediante autenticación.
