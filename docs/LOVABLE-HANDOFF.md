# Handoff para versión Lovable

Objetivo de la siguiente fase: reproducir en Lovable el MVP funcional de este repositorio sin ampliar el alcance.

## Alcance que debe conservarse

1. Landing responsive de Senda Ecuestre.
2. Próximas salidas con fecha, hora, duración, nivel, precio y plazas.
3. Reserva con nombre, contacto, número de personas, nivel y equipo/necesidades.
4. Cálculo de plazas restantes.
5. Panel Administración.
6. Alta de salidas y definición de cupo.
7. Bloqueo/reapertura de rutas.
8. Listado de reservas por salida.
9. Compartir listado por WhatsApp.
10. Persistencia en localStorage durante la fase de comparación.

## Restricción del experimento

No añadir Supabase, autenticación, pagos, API ni backend durante la reproducción inicial. El objetivo es comparar herramientas sobre el mismo alcance antes de introducir infraestructura adicional.
